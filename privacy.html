白身 (Baishen) 隐私政策

最后更新：2026-10-04（随 v1.0.5 发布）

一句话：核心检测完全在本地运行，不需要账号，不上传任何数据。 只有当你主动填入激活码并主动开启云同步之后，才会有数据离开你的电脑。

1. 不需要账号时：什么都不会上传

以下功能在完全离线状态下工作，不产生任何网络请求：

  • 读取棋盘落子序列、跑引擎复盘、计算风险分
  • 本地存档与样本库
  • 学习机制（阈值自动搜索）与黑名单
  • 自定义模型（权重包存在本机 IndexedDB）

2. 激活并登录后，会上传什么

项目内容目的
用户标识username、email账户本身
头像avatar（压缩到 256×256）主页显示
账户状态激活状态、设备 ID、最后活跃时间一码一账户、跨设备上限 3 台
样本统计条数、AI 比例等聚合数字主页数字
徽章已授予的徽章类型成就系统

3. 不会上传什么

  • 不会上传棋谱原始数据——逐手记录留在本机
  • 不会上传检测结果——风险分、每步判定只在本机计算
  • 不会上传本地设置——除非你自己打开云同步
  • 不会上传黑名单——默认不同步，需手动勾选

3.1 关于对手的数据

样本、回放存档与黑名单里带着对手的显示名。开启云同步并勾选对应类别后，这些名字会随之上传——它们是你自己采集的内容，不是我们从服务端读来的。

4. 数据存放在哪里

Supabase（PostgreSQL + Storage）托管，区域为新加坡（ap-northeast-2 邻近节点）。

5. 保留期

  • 活跃账户：数据一直保留，直到你删除
  • 注销账户：本地数据保留原位，云端数据 30 天后彻底删除
  • 激活码泄露：管理员可批量撤销，撤销不影响本地数据

6. 你的权利

  • 导出：扩展的「导入与导出」面板导出全部本地数据
  • 删除：「我的 → 注销账户」申请删除云端数据（30 天后生效）
  • 更正：「我的 → 修改资料」改用户名、邮箱、头像

7. 未成年人

本扩展面向在线五子棋的成年玩家。若可能包含未成年人，请在使用前取得监护人同意。

8. 第三方

除 Supabase 外，扩展不向任何第三方发送数据。检测引擎（Rapfi / KataGomo）在本机或你自己配置的地址运行；「自动提问」功能使用你自己填写的 LLM 接口与密钥。

9. 联系方式

管理员邮箱：mod0207613@qq.com

10. 在你自己的电脑上：哪些是明文

chrome.storage.local 本身不加密。以下内容以明文存在浏览器配置目录：

  • 「自动提问」用的 LLM API Key（导出备份会剥离）
  • 云账户登录令牌（JWT，30 天有效）——它被放在 settings 之外，导出/同步都不会带上

如果你不信任本机上的其他程序，请不要启用「自动提问」，也不要登录云账户——核心检测功能两者都不需要。

11. 在线状态与国籍的可见范围

「最后活跃时间」对其他账户一律返回空值（显示离线），这是数据层约束。国籍同理，勾选「隐藏国籍」后其他用户读到空值。

⚠ 例外：Realtime presence 频道让好友列表即时更新，任何已登录账户订阅它都能看到"现在谁在线"，但看不到历史时间戳。「隐身」让别人看到你离线，但不会把你从频道成员列表移除。
